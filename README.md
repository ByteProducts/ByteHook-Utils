# Project ByteHook Utils

## Development Setup
### Requirements

- Git
- Rokit
    - Selene
    - StyLua

### Setup

1. Fork & clone the repository
2. Install tools via rokit:
    ```ps1
    rokit install
    ```
3. Start developing!

## Linting

You can run the .bat files provided to lint from either Selene or StyLua:

### Selene:
```ps1
lint-selene.bat
```

### StyLua:
```ps1
lint-stylua.bat
```

## StyLua (Check mode):
```ps1
lint-stylua-check.bat
```
